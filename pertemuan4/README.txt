## 1. Penjelasan Program HTML

File `index.html` digunakan untuk membuat struktur halaman landing page Arunika Studio. Halaman ini terdiri dari header yang berisi nama studio dan menu navigasi, hero sebagai bagian pembuka, tiga kartu layanan, bagian tentang studio, kontak, dan footer sebagai penutup halaman.

HTML menggunakan elemen seperti `header`, `nav`, `main`, `section`, `article`, dan `footer` agar susunan halaman lebih teratur. Penggunaan `class` dan `id` membantu mengatur tampilan melalui CSS serta menghubungkan menu navigasi ke bagian tertentu.

## 2. Penjelasan Program CSS

File `style.css` digunakan untuk mengatur tampilan halaman, seperti jenis huruf, warna, ukuran, jarak, dan posisi elemen.

Properti `padding`, `margin`, dan `border` digunakan untuk menerapkan box model. Sementara itu, `box-sizing: border-box` membantu mengatur ukuran elemen agar lebih mudah disesuaikan.

Class `.card` digunakan kembali pada tiga kartu layanan, sedangkan class `.button` digunakan untuk membuat tampilan tombol yang seragam. Properti `display: flex` digunakan untuk membantu menyusun menu navigasi dan kartu layanan.

## 3. Tampilan Responsif

CSS menggunakan `@media (max-width: 767px)` agar tampilan halaman dapat menyesuaikan ukuran layar ponsel. Pada layar kecil, menu navigasi menyesuaikan susunannya dan tiga kartu layanan berubah menjadi satu kolom sehingga lebih nyaman dilihat.
