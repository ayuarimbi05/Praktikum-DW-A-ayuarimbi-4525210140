## 1. Deskripsi

Pada praktikum ini saya membuat sebuah halaman web Form Pendaftaran Kursus Berenang menggunakan HTML, CSS, dan JavaScript. Form ini digunakan untuk mengisi data peserta yang ingin mengikuti kursus berenang.

## 2. Fitur yang Dibuat

Beberapa fitur yang terdapat pada halaman form pendaftaran ini, yaitu:

1. **Data Peserta**
   - Nama lengkap peserta.
   - Usia peserta.
   - Email.
   - Nomor telepon.

2. **Informasi Kursus**
   - Pilihan jenis kelas berenang.
   - Pilihan jadwal kursus.
   - Pilihan perlengkapan yang ingin disewa.
   - Pengalaman dan tujuan belajar.
   - Catatan tambahan.

3. **Pembayaran dan Persetujuan**
   - Upload bukti pembayaran dengan format JPG, PNG, atau PDF.
   - Persetujuan data pendaftaran dan aturan keselamatan kolam.

4. **Tombol Form**
   - Daftar Kursus.
   - Reset Form.
   - Petunjuk.

## 3. Validasi Form

Pada form ini terdapat beberapa validasi, yaitu:

- Nama peserta minimal 3 karakter.
- Usia peserta antara 4 sampai 80 tahun.
- Email harus menggunakan format email yang benar.
- Nomor telepon harus diawali dengan angka 08.
- Pengalaman dan tujuan belajar minimal 20 karakter.
- Bukti pembayaran maksimal 2 MB.
- Peserta wajib menyetujui aturan kursus sebelum mendaftar.

## 4. Tampilan dan Desain

Tampilan halaman dibuat dengan desain sederhana dan menggunakan warna biru muda dan putih agar terlihat bersih dan nyaman dilihat.

CSS digunakan untuk mengatur warna, ukuran tulisan, jarak antar elemen, bentuk kotak form, tombol, serta tampilan halaman agar bisa menyesuaikan ukuran layar.

## 5. JavaScript

JavaScript digunakan untuk beberapa fungsi tambahan, yaitu:

- Menghitung jumlah karakter pada kolom pengalaman.
- Memeriksa ukuran file bukti pembayaran.
- Menampilkan pesan setelah validasi form berhasil.
- Mengosongkan form menggunakan tombol Reset.
- Menampilkan petunjuk melalui tombol Petunjuk.
