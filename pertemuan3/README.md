## Perubahan yang Saya Lakukan

Setelah membuat tampilan awal, saya melakukan perubahan pada halaman profil
dengan menggunakan CSS Inline. CSS Inline saya tambahkan langsung pada tag HTML
menggunakan `style`.

Beberapa bagian yang saya ubah yaitu warna background, warna dan ukuran teks,
ukuran foto, jarak antar bagian, border, bentuk foto, dan memberikan sedikit
efek bayangan supaya tampilannya tidak terlalu polos.

Saya menggunakan lebih dari 10 property CSS Inline, di antaranya:

- `font-family`
- `background-color`
- `margin`
- `color`
- `text-align`
- `font-size`
- `padding`
- `border`
- `border-radius`
- `box-shadow`
- `width`
- `height`
- `object-fit`
- `line-height`
- `border-bottom`
- `border-left`
