## 1. Tujuan Praktikum

Praktikum ini bertujuan untuk memahami struktur dasar HTML dan penggunaan beberapa tag untuk membuat halaman web sederhana. Pada praktikum ini, saya membuat halaman biodata pribadi menggunakan HTML.

## 2. Langkah Pengerjaan

1. Membuat folder project dengan nama `Tugas1_Biodata`.
2. Membuat file `index.html` menggunakan Visual Studio Code.
3. Menuliskan struktur dasar HTML, mulai dari `<!DOCTYPE html>`, `<html>`, `<head>`, hingga `<body>`.
4. Menambahkan judul halaman, identitas diri, program studi, minat, dan tujuan belajar.
5. Menggunakan tag heading, paragraf, teks tebal, teks miring, dan line break sesuai materi yang dipelajari.
6. Menggunakan HTML entity untuk menampilkan karakter khusus seperti `&`, `<`, `>`, dan simbol hak cipta.
7. Menyimpan file dan membuka halaman HTML melalui browser untuk melihat hasilnya.
8. Mengambil screenshot hasil tampilan pada desktop dan mobile.

## 3. Hasil Praktikum

Halaman biodata pribadi berhasil dibuat menggunakan HTML dasar. Halaman berisi identitas diri, minat, tujuan belajar, dan informasi hak cipta. Tag HTML yang dipelajari juga diterapkan pada halaman tersebut.
