## Restoran Rasa Kita

Project ini dibuat untuk latihan membuat halaman web restoran menggunakan HTML dan CSS.

## Isi Project

- `index.html` untuk struktur halaman web.
- `style.css` untuk mengatur tampilan halaman web.

## Fitur Halaman

- Navbar dengan menu Beranda, Tentang, Fasilitas, Layanan, dan Kontak.
- Banner utama berisi informasi restoran.
- Bagian menu yang menampilkan pilihan makanan.
- Kolom pencarian menu.
- Tombol untuk melihat menu dan memesan.
- Footer berisi informasi alamat dan kontak.
- Tampilan yang menyesuaikan ukuran layar desktop dan HP.

## Design System

CSS menggunakan pengaturan warna, jarak, tombol, card, dan teks agar tampilan halaman lebih konsisten. Media query digunakan untuk menyesuaikan tampilan pada layar yang lebih kecil.

## Cara Menjalankan

1. Simpan `index.html` dan `style.css` dalam folder yang sama.
2. Buka folder project di Visual Studio Code.
3. Buka file `index.html` menggunakan browser atau jalankan dengan Live Server.

## Catatan

Halaman ini masih berupa mockup. Kolom pencarian dan tombol pesan belum terhubung ke fungsi pencarian atau pemesanan yang sebenarnya.
